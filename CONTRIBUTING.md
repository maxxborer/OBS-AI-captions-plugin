# Contributing

Thank you for helping improve AI Caption Plugin.

1. Open an issue before a large behavioral change so the scope is clear.
2. Branch from `master` and keep each pull request focused.
3. Preserve the GPL-2.0-or-later notices and document any new bundled or
   downloaded dependency in `THIRD_PARTY_NOTICES.md`.
4. Build and run all tests with the commands in `DEVELOPMENT.md`.
5. Do not add cloud speech APIs, telemetry, secrets, compatibility shims, or
   another language/model without an explicit project decision and benchmark.

Security reports must follow `SECURITY.md`, not a public issue.

By contributing, you agree that your contribution is licensed under the same
GPL-2.0-or-later terms as the project.
