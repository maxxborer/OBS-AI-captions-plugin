# Code of conduct

We want this project to be a respectful, harassment-free place for everyone,
regardless of experience, identity, background, or ability.

Be constructive, discuss the code and observable behavior, respect different
levels of experience, and give people room to correct mistakes. Harassment,
threats, discrimination, sexualized attention, publishing private information,
and sustained personal attacks are not acceptable.

Maintainers may edit or remove contributions and temporarily or permanently
restrict participation when conduct threatens the project or its community.
Report conduct privately through the repository owner's GitHub profile. Do not
post sensitive evidence in a public issue. Reports will be reviewed in good
faith with attention to the safety and privacy of everyone involved.

This policy applies in project spaces and when someone publicly represents the
project.
