# AI Caption Plugin

Минимальный OBS-плагин для локальных русских субтитров. Он использует только CPU-модель sherpa-onnx T-One и не отправляет звук в интернет.

## Что осталось в плагине

- захват одного OBS-аудиоисточника или выбранного аудиотрека;
- локальное потоковое распознавание русского языка;
- Browser Source с визуальным конструктором оформления;
- настраиваемая автозамена слов, фрагментов и Regex для цензуры или исправления распознавания;
- файл с текущим текстом субтитров и OBS-подобным шаблоном даты/времени в имени;
- native closed captions для активного стрима как задел на будущее.

Google API, gRPC, API-ключи, SRT/transcript writer, вывод в запись и виртуальную камеру, OBS Text Source и связанные с ними настройки удалены.

## Установка в Windows

1. Полностью закройте OBS.
2. Распакуйте `AI-Caption-Plugin-<version>-windows-x64.zip`.
3. Запустите `ai-caption-plugin\Install-AICaptionPlugin.cmd`.

Лаунчер снимает интернет-метку только со своего `Install-AICaptionPlugin.ps1`, чтобы скачанный с GitHub пакет работал при стандартной политике `RemoteSigned`. Системная Execution Policy не изменяется и `Bypass` не используется.

Нужен современный PowerShell 7 (`pwsh`). Установщик использует рекомендуемый OBS путь `%ProgramData%\obs-studio\plugins\`, не запускает устаревший Windows PowerShell и не повышает свои права автоматически. При первой установке он скачивает локальную модель, проверяет архив и каждый рабочий файл по SHA-256, а при обновлении сохраняет только модель с верной контрольной суммой. Проверенные архивы переиспользуются; общий кэш загрузок жёстко ограничен 1 ГиБ.

## Настройка

1. Откройте `Сервис → AI Captions`.
2. Выберите чистый источник микрофона. Для сложного микса можно выбрать отдельный источник, по состоянию которого распознавание будет включаться и выключаться.
3. Оставьте плагин включённым.

Плагин захватывает звук только при наличии потребителя:

- активный Browser Source;
- включённый вывод в файл;
- активный стрим с включённым native CC;
- открытое локальное превью.

После исчезновения последнего потребителя локальная модель и захват звука останавливаются.

## Автозамена и имя файла

В разделе «Автозамена текста» добавьте пары «Заменить → На что». Режим «Слово целиком» не затрагивает совпадения внутри других слов; пустое поле «На что» удаляет найденный текст. Правила из старой версии плагина переносятся автоматически.

Имя файла принимает токены в стиле OBS. Например, `captions_%CCYY-%MM-%DD_%hh-%mm-%ss.txt` превратится в `captions_2026-08-03_14-05-09.txt` при запуске вывода. Доступны `%CCYY`, `%YY`, `%MM`, `%DD`, `%hh`, `%mm`, `%ss`; `%%` создаёт обычный знак `%`.

## Browser Source

В настройках плагина нажмите «Настроить внешний вид», затем скопируйте готовый URL в Browser Source. Адрес содержит случайный локальный порт и секретный 256-битный ключ, поэтому его нельзя заменять вручную на старый фиксированный URL или публиковать в интернете.

Страница работает только на localhost. Browser Source держит одно ограниченное соединение Server-Sent Events: пока оно открыто, распознавание активно и новые слова приходят без опроса сервера. Открывать окно `AI Captions` для этого не нужно.

## Ограничения

- Текущая T-One — русская streaming-модель. Частые названия вроде OBS, Twitch и YouTube восстанавливаются в латинице словарём замен, но это не полноценное RU+EN распознавание.
- Результат дополнительно ограничен русской кириллицей, английской латиницей, цифрами и безопасной пунктуацией; другие письменности отбрасываются целиком. Это защита вывода, а не языковой детектор: например, английский и испанский используют одну латиницу.
- Qwen3-ASR 0.6B int8 проверен экспериментально и пока не заменяет T-One: на тестовом Ryzen 7 7800X3D он оказался заметно медленнее, потребовал около 1,35 ГиБ памяти и допустил больше ошибок на русском. Подробности — в [QWEN_BENCHMARK.md](QWEN_BENCHMARK.md).
- Стандартный путь native captions в OBS использует EIA-608 и не передаёт кириллицу. Browser Source и файл поддерживают UTF-8 полностью.
- Сборка и установщик сейчас рассчитаны на Windows x64 / OBS 32.2.1.

Инструкции для разработчика находятся в [DEVELOPMENT.md](DEVELOPMENT.md).
